# 1. Tokens

**Tokenization** is the process of breaking a sentence or paragraph into smaller pieces called **tokens**.

A token can be:
- A word
- Part of a word
- A punctuation mark
- A special symbol

### Example

Sentence:

```
I love learning AI.
```

Tokens:

```
["I", "love", "learning", "AI", "."]
```

Tokenization is one of the first and most important steps in Natural Language Processing (NLP).
